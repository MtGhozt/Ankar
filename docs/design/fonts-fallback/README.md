# ankar-symbols.ttf

Fallback font for symbols missing from Hack/Inter (braille spinner U+2800–28FF, arrows, geometric shapes, misc symbols, dingbats, U+2B00–2BFF).

- Built from Cascadia Code (wght 400 instance, SIL OFL 1.1, © Microsoft) + DejaVu Sans Mono (Bitstream Vera license; DejaVu changes public domain), subset and merged with fontTools.
- Renamed to "Ankar Symbols" as both licenses require for modified versions.
- 941 codepoints, ~135 KB. No emoji (✅ U+2705, 🔥 U+1F525 stay tofu on purpose).
- Licenses: OFL-CascadiaCode.txt, LICENSE-DejaVu.txt (ship both next to the font).
