# Fonts used by mockup.html

- **Inter** (`Inter-Variable.ttf`): SIL Open Font License 1.1. https://github.com/rsms/inter
- **Hack** (`Hack-Regular.ttf`, `Hack-Bold.ttf`): MIT + Bitstream Vera license. https://github.com/source-foundry/Hack (egui already embeds Hack-Regular as its default monospace font.)

These are stand-ins: the reference app renders with Apple's SF Pro and SF Mono/Menlo, which may not be redistributed.
